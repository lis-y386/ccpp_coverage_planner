# Code of Conduct

We welcome robotics developers, learners and researchers of all backgrounds.

Be respectful and specific. Critique code and evidence rather than people. Explain assumptions, give credit, and make space for questions and different experience levels. Harassment, discriminatory language, threats, doxxing and persistent disruption are not acceptable.

Use the maintainer contact in SECURITY.md for private conduct reports. Include the relevant context without unnecessary personal data. The maintainer may ask for clarification, remove abusive content, request a change in behavior, or restrict participation, proportionate to the situation.

This is an original project policy, not a claim of affiliation with an external conduct program. It does not promise response times or continuous moderation.
